# 校园集市 PRD

## 项目定位

校园集市是一个面向单一大学校园的即时二手交易与服务撮合平台，核心目标是把校园里的闲置交易、跑腿任务和技能服务收敛到一个站点内完成。

产品主张：

- 同校真实场景，沟通链路短
- 支持线下当面交付，降低交易风险
- 二手、跑腿、技能服务统一入口
- 以校园认证、举报和权限校验构建第一版信任体系

## 第一版范围

MVP 聚焦以下模块：

- 用户系统：注册、登录、个人资料、校园认证、公开主页
- 二手商品：发布、浏览、编辑、收藏、上下架、下单
- 跑腿任务：发布、接单、流转、完成确认
- 技能服务：发布、浏览、编辑、上下架、预约下单
- 订单系统：商品、任务、服务三类订单统一管理
- 站内消息：按会话沟通
- 评价与举报：交易后评价、异常内容举报
- 管理后台：分类、关键词、举报、认证、用户和列表内容管理

## 暂不纳入第一版

- 在线支付
- WebSocket 实时消息
- 地图定位与距离排序
- AI 审核模型在线接入
- 多校区独立运营能力

## 核心约束

- 禁止代写作业、代考、论文代写、违规金融、违禁品与账号买卖
- 第一版使用关键词拦截作为内容审核基础
- 用户敏感信息不在前台公开展示
- 交易与服务交付优先采用线下或站内沟通确认
